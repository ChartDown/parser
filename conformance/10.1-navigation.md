# 10.1 Navigation

### 10.1 Navigation marks are reserved words in braces, compared without case, dots or spaces

```chartdown
## Verse
{segno} 1 | 4 {to coda} | 5 {D.S. al Coda}
## Outro
{Coda} 4 | 1
```

```json
{
  "sections": [
    {
      "rows": [{ "bars": [{ "nav": ["segno"] }, { "nav": ["tocoda"] }, { "nav": ["dsalcoda"] }] }]
    },
    { "rows": [{ "bars": [{ "nav": ["coda"] }, {}] }] }
  ],
  "warnings": []
}
```

### 10.1 A jump with no target is a warning, and the chart still renders as written

```chartdown
## Verse
1 | 4 {D.S.}
## Chorus
5 {D.C. al coda} | 1 {D.S. al fine}
```

```json
{
  "warnings": [
    { "code": "nav-needs-segno", "line": 2 },
    { "code": "nav-second-jump", "line": 4 }
  ]
}
```

### 10.1 A mark used twice is a warning

```chartdown
## Verse
{segno} 1 | {segno} 4
```

```json
{ "warnings": [{ "code": "nav-duplicate", "line": 2, "values": { "mark": "Segno" } }] }
```
