# 7.1 Unison riffs

### 7.1 R[ ... ] is a riff of single notes that shares the bar like a token

```chartdown
## Intro
1 | R[ 1 3 4 #4 5 ] | 1 | R[ 5:1 b7:1 x:2 ]
```

```json
{
  "sections": [
    {
      "rows": [
        {
          "bars": [
            {},
            {
              "items": [
                {
                  "type": "riff",
                  "notes": [
                    { "type": "note", "root": "1" },
                    { "type": "note", "root": "3" },
                    { "type": "note", "root": "4" },
                    { "type": "note", "root": "#4" },
                    { "type": "note", "root": "5" }
                  ]
                }
              ]
            },
            {},
            {
              "items": [
                {
                  "type": "riff",
                  "notes": [
                    { "type": "note", "root": "5", "beats": 1, "explicitBeats": true },
                    { "type": "note", "root": "b7", "beats": 1, "explicitBeats": true },
                    { "type": "rest", "beats": 2, "explicitBeats": true }
                  ]
                }
              ]
            }
          ]
        }
      ]
    }
  ],
  "warnings": []
}
```

### 7.1 A riff takes :beats after the closing bracket, and a note it cannot read is a warning

```chartdown
## Intro
R[ 1 3 ]:2 4:2 | R[ 1 Q 5 ]
```

```json
{
  "sections": [
    {
      "rows": [
        {
          "bars": [
            { "items": [{ "type": "riff", "beats": 2, "explicitBeats": true }, { "root": "4" }] },
            { "items": [{ "type": "riff", "notes": [{ "root": "1" }, { "root": "5" }] }] }
          ]
        }
      ]
    }
  ],
  "warnings": [{ "code": "riff-note", "line": 2, "values": { "token": "Q" } }]
}
```
