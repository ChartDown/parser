# 11.3 Tempo changes

### 11.3 @tempo changes the tempo from the next row onward, and marks the change

```chartdown
---
tempo: 72
---
## Bridge
1 | 4
@tempo 90
5 | 1
```

```json
{
  "sections": [{ "rows": [{ "tempo": 72 }, { "tempo": 90, "tempoChange": 90 }] }],
  "warnings": []
}
```

### 11.3 A tempo it cannot read is a warning

```chartdown
## Bridge
@tempo fast
1
```

```json
{ "warnings": [{ "code": "bad-tempo-directive", "line": 2 }] }
```
