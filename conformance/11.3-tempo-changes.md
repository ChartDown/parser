## The beat unit (0.9)

### 11.3 A tempo can say what one beat is: 58 q. is 174 eighth notes a minute

```chartdown
---
meter: 6/8
tempo: 58 q.
---
## Verse
1 | 4
```

```json
{
  "meta": {
    "meter": "6/8",
    "tempo": "58 q."
  },
  "sections": [
    {
      "rows": [
        {
          "meter": "6/8",
          "tempo": 58,
          "tempoUnit": "q.",
          "tempoEpm": 174
        }
      ]
    }
  ],
  "warnings": []
}
```

### 11.3 A written unit stays when the meter changes; @tempo takes one too, with or without a space

```chartdown
---
meter: 6/8
tempo: 87 q
---
## A
1 | 4
@meter 4/4
5 | 1
@tempo 174e
4 | 1
```

### 11.3 ? says the unit isn't known yet: the chart is valid and no unit is assumed

```chartdown
---
meter: 6/8
tempo: 58 ?
---
## Verse
1 | 4
@tempo 60 q.
5 | 1
```

```json
{
  "meta": {
    "tempo": "58 ?"
  },
  "sections": [
    {
      "rows": [
        {
          "tempo": 58,
          "tempoUnit": null,
          "tempoEpm": null
        },
        {
          "tempo": 60,
          "tempoUnit": "q.",
          "tempoEpm": 180
        }
      ]
    }
  ],
  "warnings": []
}
```
