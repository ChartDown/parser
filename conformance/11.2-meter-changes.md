# 11.2 Meter changes

### 11.2 @meter changes the meter from the next row onward, and marks the change

```chartdown
---
meter: 4/4
---
## Bridge
1 | 4
@meter 6/8
5 | 1
@meter 4/4
4
```

```json
{
  "sections": [
    {
      "rows": [
        { "meter": { "beats": 4, "unit": 4 } },
        { "meter": { "beats": 6, "unit": 8 }, "meterChange": { "beats": 6, "unit": 8 } },
        { "meter": { "beats": 4, "unit": 4 }, "meterChange": { "beats": 4, "unit": 4 } }
      ]
    }
  ],
  "warnings": []
}
```

### 11.2 [m:N/D] is the meter of one bar, and the next bar goes back

```chartdown
## Bridge
4 | 5 | [m:2/4] 5:1 4:1 | 1
```

```json
{
  "sections": [
    {
      "rows": [
        {
          "bars": [{}, {}, { "meter": { "beats": 2, "unit": 4 } }, {}]
        }
      ]
    }
  ],
  "warnings": []
}
```

### 11.2 The beats of a bar add up to the meter in effect for that bar

```chartdown
## Bridge
@meter 6/8
1:3 4:3 | [m:2/4] 5:1 4:2
```

```json
{ "warnings": [{ "code": "beats-mismatch", "line": 3, "values": { "sum": 3, "beats": 2 } }] }
```

### 11.2 The meter stays in effect in later sections, and a meter it cannot read is a warning

```chartdown
## Bridge
@meter 3/4
1
## Tag
4
@meter nope
```

```json
{
  "sections": [
    { "rows": [{ "meter": { "beats": 3 } }] },
    { "rows": [{ "meter": { "beats": 3 } }] }
  ],
  "warnings": [{ "code": "bad-meter-directive", "line": 6 }]
}
```
