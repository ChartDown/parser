# 5.2 Reusing a section

### 5.2 @use copies the rows of the earlier section and keeps its own notes

```chartdown
## Chorus
> MD: Open it up.
4 | 1 | 5 | 6m
## Chorus 2
> MD: A touch bigger.
@use Chorus
```

```json
{
  "sections": [
    {},
    {
      "name": "Chorus 2",
      "use": { "name": "Chorus", "line": 6 },
      "notes": [{ "text": "A touch bigger." }],
      "rows": [
        {
          "bars": [
            { "items": [{ "root": "4" }] },
            { "items": [{ "root": "1" }] },
            { "items": [{ "root": "5" }] },
            { "items": [{ "root": "6" }] }
          ]
        }
      ]
    }
  ],
  "warnings": []
}
```

### 5.2 Copied rows use the current key

```chartdown
---
key: G
---
## Chorus
4 | 1
## Bridge
@key A
5 | 5
## Chorus 2
@use Chorus
```

```json
{
  "sections": [
    { "rows": [{ "key": { "root": "G" } }] },
    {},
    { "rows": [{ "key": { "root": "A", "minor": false } }] }
  ]
}
```

### 5.2 @use of a section that does not exist earlier is a warning

```chartdown
## Verse
@use Chorus
## Chorus
1
```

```json
{
  "sections": [{ "rows": [] }, {}],
  "warnings": [{ "line": 2, "code": "use-not-found", "values": { "name": "Chorus" } }]
}
```

### 5.2 @use must be the only content line: a section with its own rows keeps them, with a warning

```chartdown
## Verse
1 | 4
## Verse 2
@use Verse
5 | 1
```

```json
{
  "sections": [
    {},
    { "rows": [{ "bars": [{ "items": [{ "root": "5" }] }, { "items": [{ "root": "1" }] }] }] }
  ],
  "warnings": [{ "line": 4, "code": "use-with-rows" }]
}
```
