# 9.1 Cues and notes for one pass

### 9.1 {2x drums: text} is a cue for the drummer on the second pass

```chartdown
## Bridge
|: 1 {2x drums: in} | 4 | 5 {1x,3x: stop} | 1 :| 3x
> MD 2x bass: Walk up.
```

```json
{
  "sections": [
    {
      "notes": [{ "md": true, "roles": ["bass"], "passes": [2], "text": "Walk up." }],
      "rows": [
        {
          "bars": [
            { "cues": [{ "roles": ["drums"], "passes": [2], "text": "in" }] },
            {},
            { "cues": [{ "roles": ["everyone"], "passes": [1, 3], "text": "stop" }] },
            {}
          ]
        }
      ]
    }
  ],
  "warnings": []
}
```

### 9.1 A pass counts only when a colon follows it

```chartdown
## Bridge
|: 1 {2x louder} | 4 :|
```

```json
{
  "sections": [
    {
      "rows": [
        { "bars": [{ "cues": [{ "roles": ["everyone"], "passes": [], "text": "2x louder" }] }, {}] }
      ]
    }
  ],
  "warnings": []
}
```

### 9.1 A pass on a bar outside any repeat, or on a note in a section with no repeat, is a warning

```chartdown
## Verse
> MD 2x drums: Crash.
1 {2x drums: in} | 4
```

```json
{
  "warnings": [
    { "code": "note-pass-without-repeat", "line": 2 },
    { "code": "pass-without-repeat", "line": 3 }
  ]
}
```
