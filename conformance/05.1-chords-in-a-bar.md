# 5.1 Chords in a bar

### 5.1 Chords inside one bar share it evenly

```chartdown
## A
1 4 | 6m 5
```

```json
{
  "sections": [
    {
      "rows": [
        {
          "bars": [
            {
              "items": [
                { "root": "1", "beats": 1, "explicitBeats": false },
                { "root": "4", "beats": 1, "explicitBeats": false }
              ]
            },
            { "items": [{ "root": "6" }, { "root": "5" }] }
          ]
        }
      ]
    }
  ],
  "warnings": []
}
```

### 5.1 :beats splits a bar unevenly

```chartdown
## A
1:3 4:1
```

```json
{
  "sections": [
    {
      "rows": [
        {
          "bars": [
            {
              "items": [
                { "root": "1", "beats": 3, "explicitBeats": true },
                { "root": "4", "beats": 1, "explicitBeats": true }
              ]
            }
          ]
        }
      ]
    }
  ],
  "warnings": []
}
```

### 5.1 Beats may be fractional

```chartdown
## A
1:1.5 4:2.5
```

```json
{
  "sections": [{ "rows": [{ "bars": [{ "items": [{ "beats": 1.5 }, { "beats": 2.5 }] }] }] }],
  "warnings": []
}
```

### 5.1 Beats count in the units of the meter's top number

```chartdown
---
meter: 6/8
---
## A
1m:3 4m:3 | b6:4 5:2
```

```json
{ "warnings": [] }
```

### 5.1 Beats that do not add up to the meter are a warning

```chartdown
---
meter: 3/4
---
## A
1:2 4:2
```

```json
{ "warnings": [{ "line": 5, "code": "beats-mismatch", "values": { "sum": 4, "beats": 3 } }] }
```

### 5.1 Without :beats, any number of chords fills the bar

```chartdown
---
meter: 3/4
---
## A
1 4 5 6m
```

```json
{ "warnings": [] }
```
