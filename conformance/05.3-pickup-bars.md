# 5.3 Pickup bars

### 5.3 [p:N] starts a pickup of N beats, which is bar 0

```chartdown
## Intro
[p:2] 5 | 1 | 4
```

```json
{
  "sections": [
    {
      "rows": [
        {
          "bars": [
            { "number": 0, "pickup": 2, "items": [{ "root": "5" }] },
            { "number": 1, "items": [{ "root": "1" }] },
            { "number": 2, "items": [{ "root": "4" }] }
          ]
        }
      ]
    }
  ],
  "warnings": []
}
```

### 5.3 The chords of a pickup share its beats, and :beats should add up to them

```chartdown
## Intro
[p:2] 5:1 4:1 | 1
[p:2] 5:2 4:1
```

```json
{
  "warnings": [
    { "code": "pickup-beats-mismatch", "line": 3 },
    { "code": "pickup-not-first", "line": 3 }
  ]
}
```

### 5.3 A pickup needs more than 0 and fewer beats than the meter

```chartdown
## Intro
[p:4] 5 | 1
```

```json
{
  "sections": [{ "rows": [{ "bars": [{ "items": [{ "root": "5" }] }, {}] }] }],
  "warnings": [{ "code": "pickup-length", "line": 2, "values": { "beats": 4 } }]
}
```

### 5.3 A bar cannot have both a pickup and a one-bar meter

```chartdown
## Intro
[p:1] [m:2/4] 5 | 1
```

```json
{ "warnings": [{ "code": "pickup-and-meter", "line": 2 }] }
```
