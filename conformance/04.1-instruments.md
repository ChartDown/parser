# 4.1 Instruments (roles)

### 4.1 all, band and everyone mean everyone

```chartdown
## A
> MD all: One.
> MD band: Two.
> MD everyone: Three.
1
```

```json
{
  "sections": [
    { "notes": [{ "roles": ["everyone"] }, { "roles": ["everyone"] }, { "roles": ["everyone"] }] }
  ],
  "warnings": []
}
```

### 4.1 drums, drum and perc mean drums; bass means bass

```chartdown
## A
> MD drums drum perc: Together.
> MD bass: Roots.
1
```

```json
{ "sections": [{ "notes": [{ "roles": ["drums"] }, { "roles": ["bass"] }] }], "warnings": [] }
```

### 4.1 Saxophone, trumpet, trombone and violin, by short or long name

### 4.1 A custom instrument declared in the header works in notes and cues

```chartdown
---
instruments: cello, banjo
---
## A
> MD cello: Long notes.
1 {banjo: in}
```

```json
{
  "instruments": ["cello", "banjo"],
  "sections": [
    {
      "notes": [{ "roles": ["cello"] }],
      "rows": [{ "bars": [{ "cues": [{ "roles": ["banjo"], "text": "in" }] }] }]
    }
  ],
  "warnings": []
}
```

### 4.1 Custom instrument ids are lowercase letters, digits and -

```chartdown
---
instruments: Cello, steel-gtr2, bad_id
---
## A
1
```

```json
{
  "instruments": ["cello", "steel-gtr2"],
  "warnings": [{ "line": 2, "code": "instrument-id", "values": { "id": "bad_id" } }]
}
```

### 4.1 An unknown name in an MD note is a warning, and the note is shown to everyone

```chartdown
## A
> MD kazoo: Loud.
1
```

```json
{
  "sections": [{ "notes": [{ "md": true, "roles": ["everyone"], "text": "Loud." }] }],
  "warnings": [{ "line": 2, "code": "unknown-instrument", "values": { "name": "kazoo" } }]
}
```

### 4.1 An unknown name in a cue is a warning, and the whole cue is shown to everyone

```chartdown
## A
1 {kazoo: in}
```

```json
{
  "sections": [
    { "rows": [{ "bars": [{ "cues": [{ "roles": ["everyone"], "text": "kazoo: in" }] }] }] }
  ],
  "warnings": [{ "line": 2, "code": "unknown-cue-instrument", "values": { "name": "kazoo" } }]
}
```
